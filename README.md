# Sana Vita — сайт медичного центру (курсова №2, UI/UX)

Верстка 5 сторінок за макетами Hi-fi у Figma (мобайл 360 + десктоп 1440):

| Сторінка | Файл |
|---|---|
| Головна | `index.html` |
| Лікування геморою | `hemorrhoids.html` |
| Ціни | `prices.html` |
| Сторінка лікаря (шаблон, Бондаревич С. М.) | `doctor.html` |
| Контакти | `contacts.html` |

## Як відкрити
Просто відкрийте `index.html` у браузері. Нічого встановлювати не треба.

Щоб опублікувати: **Settings → Pages → Branch: main → Save**, і через хвилину сайт буде за адресою `https://<логін>.github.io/<репозиторій>/`.

## Що всередині
- `css/style.css` — усі стилі. Кольори, шрифти та відступи винесені в змінні на початку файлу.
  Десктоп від 1240 px (сітка 1180), планшет 768–1239 px, мобайл до 767 px.
- `js/main.js` — мобільне меню, гортання відгуків, категорії цін, подяка після відправки форми.
- `img/icons/` — іконки, експортовані з Figma (SVG). `img/logo.svg`, `img/logo-white.svg` — логотипи.
- `img/photos/` — фото лікарів з сайту sanavita.com.ua.

## Що варто доробити
- Фото в першому екрані головної, на сторінці «Геморой» і фото Вилегжаніна Д. С. — зараз підписані заглушки (`.ph`). Замініть на `<img>`.
- Відповіді на 4 питання FAQ і списки послуг інших категорій цін позначені `[___]` — їх немає в макеті.
- Форми не відправляють дані нікуди (немає сервера), лише показують подяку.
